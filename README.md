## What I do

- **AI agents in production.** Conversational and task agents on Google Cloud Vertex AI for enterprise clients, working with teams in Spain and the United States.
- **Integrations.** Connecting models and APIs to existing products to remove manual steps.
- **Full-stack around it.** Architecture, backend and a React / Vue frontend, from database to interface.

Earlier work includes a Bosch technical-service mobile app (Kotlin), VR/AR apartment visualisation (C#, Blender) and real-time object detection mirrored in a 3D web view.
